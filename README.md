# 🪪 1024 程序员身份证生成器

> **WorkBuddy「1024 造物挑战」程序员节应用创作大赛 · 参赛作品**
> Made with WorkBuddy · 纯前端 · 单文件 · 零依赖 · 数据不出本机

填一下你的信息，生成一张专属「程序员身份证」：能力雷达、称号等级、1024 勋章、座右铭、专属条形码一应俱全，**一键下载图片去晒**，冲社媒加分。

## ✨ 它能做什么

- **确定性生成**：同一种输入永远生成同一张卡（种子哈希 + mulberry32 伪随机），可放心分享
- **能力雷达**：发量指数 / 技术广度 / Bug 亲和力 / 咖啡依赖 / 摸鱼指数 / 1024 忠诚度，六维自测
- **称号与勋章**：按综合分定级（青铜萌新 → 钻石程序猿），附随机梗称号（Bug 克星 / 摸鱼艺术家…）
- **专属头像**：根据输入种子生成对称 identicon 头像
- **一键导出**：Canvas 直接绘制卡片，`toDataURL` 一键下载 PNG；分享文案自动带上 `#WorkBuddy #1024程序员节` 话题
- **输入微调**：编程年限影响发量与广度、记事本用户 Bug 亲和力 +15……让卡片"像那么回事"

## 🚀 如何体验

单文件网页应用，无需安装、无需联网：

1. 打开体验链接，填入昵称 / 语言 / 年限 / 编辑器 / 最怕的事
2. 点击「🎯 生成身份证」→「⬇️ 下载图片」
3. 或点「🎲 随机一个」先看看别人的卡长什么样

## 🧱 技术实现

- 单 `index.html`，内联 CSS/JS，无外部依赖与请求
- 卡片完全由 Canvas 2D 绘制（2x 分辨率导出），所见即所得
- 确定性伪随机：FNV-1a 哈希 + mulberry32，保证"同人同卡"

## 🔒 隐私说明

所有计算均在浏览器本地完成，不上传任何数据。
